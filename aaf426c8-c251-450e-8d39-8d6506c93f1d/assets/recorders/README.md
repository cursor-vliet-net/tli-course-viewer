# Audio recorders (JSON)

These configs power the in-page audio recorder. A spoken-practice mount points at a JSON
document (file, inline blob, or object passed to the mount API). The component always
renders the same one-line **icon-only** UI from that JSON: play original · replay (disabled until a take) ·
half-button gap · record/stop · info. Buttons have no visible text captions; accessible
names use `aria-label` / `title` in the EN|KH UI language. Takes stay in the browser; they
are not uploaded and not scored. There are no confirm/discard/self-mark buttons.

## Mount

External file (paths relative to `viewer/assets/`, same idea as scene players):

```html
<div class="tli-audio-recorder" data-recorder="recorders/s001-say-my-name.json"></div>
```

Inline JSON blob (what the quiz builder emits from a spoken question):

```html
<div class="tli-audio-recorder">
  <script type="application/json">
  {
    "version": 1,
    "id": "s001.say-my-name",
    "model": { "en": "Hello. My name is Bora." },
    "audioFile": null
  }
  </script>
</div>
```

Programmatic:

```js
TLIAudioRecorder.mount(el, {
  version: 1,
  id: "demo",
  model: { en: "Hello. My name is Bora." },
  audioFile: null
});
```

Reload after editing a JSON file under `recorders/` — no Markdown rebuild needed for that
file. Quiz inline blobs are regenerated by `build_viewer.py` from the question bank.

## Schema

```json
{
  "version": 1,
  "id": "s001.say-my-name",
  "model": {
    "en": "Hello. My name is Bora."
  },
  "audioFile": null,
  "help": {
    "en": "You can record yourself and compare with the given pronunciation in the lesson. Try again until you're satisfied.",
    "km": 'អ្នកអាចថតសំឡេងខ្លួនឯង រួចប្រៀបធៀបជាមួយការបញ្ចេញសំឡេងក្នុងមេរៀន។ សាកថតម្តងទៀតរហូតដល់ពេញចិត្ត។'
  }
}
```

| Field | Meaning |
|---|---|
| `version` | Schema version. Use `1`. |
| `id` | Optional stable id (often the question-bank id). |
| `model.en` | **Required.** English model line the pupil should say. Play original uses this for browser `speechSynthesis` when there is no usable audio file. **Never** put Khmer here for TTS — Khmer is not sent to `speechSynthesis`. |
| `model.km` | Optional. Display-only / future use. Ignored for playback and TTS. |
| `audioFile` | Optional URL/path relative to `viewer/assets/`, or absolute/`assets/…`. When set, Play original tries the file first and falls back to English TTS from `model.en` if the file fails. `null` / omitted → TTS only. |
| `help` | Optional. `{ "en": "…", "km": "…" }` overrides the default help-dialog body. Optional nested `title: { "en", "km" }` overrides the dialog title / info-button name. Omitted → built-in defaults. |

## UI (fixed by the component)

One horizontal **icon-only** row:

1. **Play original** — Font Awesome `fa-play`. Plays `audioFile` if present, else English
   TTS of `model.en`. Accessible name: Listen / ស្តាប់.
2. **Replay slot** — always shows the replay control with `assets/icons/person-play.svg` (person silhouette + play triangle). Starts disabled at 0.8 opacity; after a take it is enabled at full opacity. Accessible name: Play recording / ចាក់ថត.
3. **Gap** — empty space half a button wide.
4. **Record / Stop** — `fa-microphone` when idle, `fa-stop` while recording. A new take
   replaces the previous take. Accessible names: Record / ថត and Stop / ឈប់.
5. **Info** — Font Awesome `fa-circle-info`. Opens a short help dialog in the current UI
   language. Accessible name: How this works / របៀបប្រើ.

Decorative icons use `aria-hidden="true"`; the button carries `aria-label` and `title`.

A short `role="status"` line under the row reports mic errors or “Recording…”. Privacy: the
take stays in the page; speech-to-text is not used; nothing is uploaded or scored.
